Agent Development Kit（ADK）旨在帮助开发者快速构建、管理、评估和部署由AI驱动的 Agent。这些快速入门指南可以让你在不到20分钟内设置并运行一个简单的 Agent。

## Python 快速入门

在几分钟内创建你的第一个 Python ADK Agent。

[从 Python 开始](/docs/adk/build/get-started/python/)

## Go 快速入门

在几分钟内创建你的第一个 Go ADK Agent。

[从 Go 开始](/docs/adk/build/get-started/go/)

## Agents CLI 快速入门

使用你的编码 Agent 创建第一个 ADK Agent。

[从 Agents CLI 开始](/docs/adk/build/get-started/agents-cli/)

## 迁移到 ADK

使用 Agents CLI 将现有 Agent 和工作流程迁移到 ADK。

[迁移到 ADK](/docs/adk/build/get-started/migrate-to-adk/)

要开始，请参阅 [技术概览](/docs/adk/components/technical-overview/)。
