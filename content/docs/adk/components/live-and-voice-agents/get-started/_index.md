快速入门在 `adk web` 中运行您的 Agent 程序，该环境提供了一个浏览器客户端，已能捕捉麦克风输入、播放 Agent 的回复并显示文字记录。您只需编写 Agent 并选择模型，无需处理客户端代码。

您的 Agent 需要一个能够保持双向流式连接的模型。请参见 [支持的模型](/docs/adk/components/live-and-voice-agents/supported-models/) 获取当前列表及配置方法。

## 选择您的语言 {#choose-your-language}

## Python {#next-steps}

设置 ADK，构建语音 Agent，并在 `adk web` 中与其交互。

## 后续步骤

- **[配置](/docs/adk/components/live-and-voice-agents/building/configuration/)** — 设置语音、语言、转录和对话轮次检测。
- **[工具](/docs/adk/components/live-and-voice-agents/building/tools/)** — 为 Agent 提供可在对话中调用的工具，包括能在运行时流传结果的工具。
- **[会话](/docs/adk/components/live-and-voice-agents/building/sessions/)** 和 **[事件](/docs/adk/components/live-and-voice-agents/building/events/)** — `run_live()` 循环及其返回的所有内容。
- **[评估](/docs/adk/components/live-and-voice-agents/production/evaluation/)** — 在发布前对语音会话进行评分。
- **[构建自定义服务器](/docs/adk/components/live-and-voice-agents/production/build-a-custom-server/)** — `adk web` 是开发客户端，这就是在您自己的服务器和客户端后运行在线 Agent 的方法。
